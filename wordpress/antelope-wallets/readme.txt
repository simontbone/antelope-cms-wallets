Connect WordPress to Antelope blockchains using Anchor and WAX My Cloud Wallet.

== Description ==
Provides the [antelope_wallet] shortcode with wallet login, session restore, token balance, token transfer, and advanced contract action signing. Built-in presets are included for WAX, Telos, and Vaulta mainnets. Private keys remain inside the user's wallet. My Cloud Wallet is offered only for WAX; Anchor supports all included presets.

== Installation ==
1. Upload the antelope-wallets directory to wp-content/plugins/ or install the release ZIP.
2. Activate Antelope Wallets.
3. Configure Settings > Antelope Wallets and choose a network preset or Custom.
4. Add [antelope_wallet] to a page.
