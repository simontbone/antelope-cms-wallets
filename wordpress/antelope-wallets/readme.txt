Connect WordPress to Antelope blockchains using Anchor and WAX My Cloud Wallet.

== Description ==
Provides the [antelope_wallet] shortcode with wallet login, session restore, WAX/token balance, token transfer, and advanced contract action signing. Private keys remain inside the user's wallet.

== Installation ==
1. Upload the antelope-wallets directory to wp-content/plugins/ or install the release ZIP.
2. Activate Antelope Wallets.
3. Configure Settings > Antelope Wallets.
4. Add [antelope_wallet] to a page.
