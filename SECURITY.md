# Security

- Never submit private keys, seed phrases, or recovery phrases to WordPress, Drupal, this project, or a support issue.
- Signing is delegated to Anchor or WAX My Cloud Wallet through WharfKit.
- The CMS stores only public chain configuration such as chain ID, RPC endpoint, token contract, symbol, and feature toggles.
- The advanced contract-action form is intentionally powerful. Users must review every wallet prompt before signing.
- RPC endpoints are called directly by the browser; configure only endpoints you trust.
